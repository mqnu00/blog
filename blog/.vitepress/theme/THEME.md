# 主题交付案：晴山新霁 · 远岫凝青 v2

> 基于 `#8299B5` 的博客全站主题配色（中国传统色 · 国色美学 · 明朗清爽版）

## 一、方案主题与美学意境

**晴山新霁 · 远岫凝青** —— v2 明朗清爽

苏轼所谓「山色空蒙雨亦奇」，王维「山路元无雨，空翠湿人衣」，
皆是这一抹钴蓝如洗、霁青跃亮的雨后远山气象。

v2 针对「品牌蓝不够明显 / 整体太旧暗沉」的反馈做了全面提亮：
- **底衬**：从暖黄「鱼肚白」换为冷调「月白」`#eef7f2`——清冽如晨露；
- **主体**：从灰闷「蝶翅蓝」换为饱和「钴蓝系」`#1576a0` / `#1a94bc`——鲜亮夺目；
- **深色模式**：霁青 `#63bbd0` 作为悬停高亮——夜色中跃出的一缕天光。
